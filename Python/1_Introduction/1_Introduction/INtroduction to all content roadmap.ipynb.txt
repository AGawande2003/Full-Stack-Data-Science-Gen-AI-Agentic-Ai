# Day 01: Full Stack Data Science & AI — Course Introduction

## 📌 Overview

Day 01 establishes the technical direction for a structured journey across **Full Stack Data Science, Generative AI, and Agentic AI**.

The curriculum progresses from programming and data fundamentals toward machine learning, advanced AI systems, Retrieval-Augmented Generation (RAG), Agentic AI, Model Context Protocol (MCP), and related production-oriented technologies.

The objective is to develop the technical foundation required to design and implement practical Data and AI solutions.

---

## 🎯 Technical Scope

The overall curriculum covers three major engineering areas:

### 1. Full Stack Data Science

The Data Science track progresses through areas including:

* Data Science fundamentals
* Programming
* Python
* Python Data Structures
* Functions
* Object-Oriented Programming
* Production-level Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy
* Statsmodels

These components establish the programming, data manipulation, analysis, visualization, and statistical foundation required for subsequent AI development.

### 2. Generative AI

The Generative AI track introduces technologies and concepts around:

* Generative AI
* Large Language Models (LLMs)
* Prompt Engineering
* Retrieval-Augmented Generation (RAG)
* Vector Databases
* AI application development

The focus is on understanding how modern generative systems can be integrated into practical applications.

### 3. Agentic AI

The advanced AI track expands toward autonomous and tool-enabled AI systems, including:

* Agentic AI
* AI Agents
* Agent workflows
* Model Context Protocol (MCP)
* Agent frameworks
* CrewAI
* SmolAgent
* Memory and context systems
* Tool-based AI workflows
